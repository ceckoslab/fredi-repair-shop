# TelSoft logo archive

Fredi selected **08 — Pyramid Monogram** for the website. The other concepts are preserved here for future reference and reuse.

- `originals/` contains all ten original 1254 × 1254 PNG concept images.
- `web/` contains the optimized WebP versions used during the logo preview.
- Open `gallery.html` in a browser to compare the numbered concepts. Keep it alongside `originals/` so the images load. The gallery works offline.
- `previous-favicon.svg` preserves the earlier generic T icon.

The active website asset is `public/images/telsoft-logo.webp`. This archive is kept in the repository, outside the public website assets. The PNGs are concept artwork on white backgrounds, not vector masters.
